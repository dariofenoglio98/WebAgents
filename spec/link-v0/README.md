# link.v0 machine contracts

The normative text is [`../link-v0.md`](../link-v0.md). This folder holds what a runtime
implements against and what the tests validate:

| File | What it is |
|---|---|
| `workflow.schema.patch.json` | RFC 6902: on `step` and `node` of `workflow.schema.json`, the type `link`, its fields (`dependency`; for a slot `slot`, `locate`, `request`, `reason`, `max_joins`, `budget`) and its conditionals (§2.2, §2.3: a link names a dependency or a slot, never both, and carries no field of another type). Applied to agentpkg's live schema by T65; the Chrome copy is synced from it by T66. |
| `manifest.schema.patch.json` | RFC 6902: a dependency record of `manifest.schema.json` gains the optional `id` and `signer` (§2.1). |

Two further contracts live with agentpkg's schemas, because a host renders them:
`agentpkg/src/agentpkg/schemas/link-join-card.schema.json`, the facts of a join card (L-34), and
`agentpkg/src/agentpkg/schemas/budget-raise-card.schema.json`, the facts of the budget-raise
card (L-43). A runtime validates the facts against them before a card is shown.

A slot's outcome and the request-building call's schema are built by the runtime from
declarations (§2.3, §6), so there is no contract file for them. The enforcement cases (§10) are
listed in [`examples/link/cases/cases.json`](../../examples/link/cases/cases.json) and built by
the probe `agentpkg/tests/link_probe.py`; `conformance/drivers/link_probe.py` writes one case
for a runner of both runtimes, with its join fixture (§10) where the case has a person or a
recorded web. The example packages are under `agents/` (the planner `travel-planner` and the
three it can ask), generated by
[`examples/link/make_link_examples.py`](../../examples/link/make_link_examples.py), which also
writes the planner 0.2.0 (the tree under `agents/travel-planner/`, the version with a slot,
signed as `dist/travel-planner-0.2.0.agent.pkg`; 0.1.0, signed as
`dist/travel-planner-0.1.0.agent.pkg`, is the script's `planner_010()`) and its join fixture
(`examples/link/join-fixture.json`).

Run the checks from the repository root:

```sh
agentpkg/.venv/bin/python -m pytest agentpkg/tests/test_link_cases.py agentpkg/tests/test_link_runtime.py agentpkg/tests/test_link_join.py agentpkg/tests/test_link_packages.py
agentpkg/.venv/bin/python scripts/verify_link_run.py <an agentpkg run --out directory>
```
