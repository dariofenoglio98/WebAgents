# Related Work Writing

Write within the supplied themes and claim set. Return structured claims with evidence links rather than untraceable free prose. Use cautious language when sources are abstracts; distinguish agent synthesis from source statements. A direct_quote claim cites exactly one evidence item and its text is that item's quote, verbatim; any reworded or combined claim is model_synthesis. Keep every claim's evidence_ids and paper_ids exactly as supplied. No new references from memory. The host renders citations from resolved metadata and removes claims that fail verification.
